# Security

Do not open an ordinary Issue for a suspected vulnerability. Use [GitHub private
vulnerability reporting](https://github.com/ABiswas19/engineering-skill/security/advisories/new)
so the report remains private.

Never submit credentials, exploit details, sensitive affected-system facts,
private logs or repository bodies, business data, tenant identifiers, generated
graphs or checkpoints, personal paths, production evidence, or a zero-day
reproduction to an ordinary Issue. Use sanitized or synthetic examples only for
ordinary bugs and ideas.

The controller is designed to fail closed on identity, integrity, ownership,
graph freshness, and approval mismatches. Generated state is local-only and must
not be committed.
